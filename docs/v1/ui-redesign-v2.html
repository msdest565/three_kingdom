只看眼前这一仗

  • 出战编队在地图下方、需滚动→叠放头像 + 总战力 + 整备方钮固定在主按钮上方

一键强化装备的规则

只提升强化等级，不自动升品，也不换装。每格 +1，按单价从低到高依次扣费，资源不够就停在当前那一格，并提示“已强化 3 / 4 格”。按下后四个格子依次弹跳，角标数字跳动，战力滚动上涨，并在右上飘出 +数值。满级的格子跳过，四格都满级时按钮置灰。

03 · 工坊

对齐、合并、统一

三处修正。分段标签改成真正的垂直居中；背包的分类筛选和「清理」并成一行工具栏，掉率收进 ⓘ；所有装备统一成一种方格，背包、武将详情、换装选择、锻造和胜利箱都用它。

  • 科技 / 锻造 / 背包 文字居中偏下→分段条高度 52 = 4 + 44 + 4；按钮占满轨道，并用 grid 居中，文字落在视觉中线上
  • 「清理闲置」单独占一整行，筛选在下一行换行→一行工具栏：左边是“全部 + 四个槽位图标”的分段筛选（角标为数量），右边是朱砂色小按钮「清理 7」
  • 背包两列文字卡，高度随“闲置 / 穿戴中 / 分解按钮”变化→四列等大装备格；名称一行省略；点格子在底部详情条操作（换装 / 分解）
  • “胜利箱掉率”折叠段落占底部→件数行右侧的「ⓘ 掉率」，点开浮层显示
  • 科技卡两列，“Lv0/10” 被书法字体写歪→科技改为单列等高行；名字用书法，数字一律用宋体数字
根因分段文字为什么偏下

ui-v2.css 把 .segmented 设成 42px 高、内边距 4px，只剩 34px；但 campaign.css 给按钮的 min-height:44px 还在生效。按钮比轨道高 10px，向下溢出，文字跟着往下偏。修法是轨道改为 52px，按钮 height:100%;min-height:0，用 grid 居中，同时保住 44px 的点击高度。

一并修装备数量与上限

背包上限是 4000 件，实际碰不到，所以不显示“18 / 4000”。只显示总件数和闲置件数，筛选角标显示各槽数量；上限只在接近时（≥ 3900）出现朱砂提示。

05 · 待你决定

动手前请确认这几处

  1. 武将详情改成整页，不再用底部弹层弹层最高只有 88% 屏高，放不下一页式布局。整页从武将列表推入，左上角返回，顶部 ‹ › 可以在已拥有的武将之间翻页。
  2. 四项属性选哪四个样机用的是攻击、射程、攻速、守城。前三项是本人数值（武器和战马会改变），守城是铠甲给全队的城关耐久。兵符的“全队营伤”放在兵符格的弹出卡里。也可以换成“无双伤害”。
  3. 技能介绍文案需要新写数据里只有技能名和几何参数，没有说明文字。我会按每个技能的实际效果为 15 名武将各写一句话加 2–3 个标签，你审一遍。预览按真实形状绘制：扇区、圆、直线冲锋、三连穿等。
  4. 一键强化装备的范围样机只升强化等级，不升品、不换装。也可以合并成“一键整备本将”：先换上背包里更好的闲置装备再强化。请选一种。
  5. 首页去掉「情报」按钮情报入口改为长按当前关。键盘和读屏用户通过当前关节点的“查看情报”操作打开。如果担心新玩家发现不了，前三关可以在焦点地图上显示一次“长按看情报”的提示。
