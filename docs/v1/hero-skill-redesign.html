边界

不变的规则

数值不动

damageByClass、tickDamageByClass、斩杀名单、击退量、增益量与时长全部沿用。只改形状、落点和表现。

每敌每次最多命中一次

多段技能（司马懿三雷、刘备援军推进）的 maxHitsPerEnemyPerCast 仍为 1；持续技能的跳数上限不变。

演出锁 0.9 秒

夏侯惇跳出跳回、许褚前扑都在 0.9 秒内完成，全队技能队列的节奏不变。

武将不会受伤

跳进兵堆只是表现：武将没有 HP、不被攻击、不阻挡敌人。命中判定只看锁定落点。

落点在施放时锁定

手动施放在入队时锁定，自动施放在执行时复核，和现在的 targetLockedAtCast 一致。特效只解释已经命中的范围，范围外的敌人不画受击。

减弱动态

去掉跳跃弧线、旗帜飞行、潮浪推进的位移，改为落点直接闪现 + 范围描边；保留命中、倒地、增益图标。

请确认这几处

  1. 整体强度会明显上升

    八将的覆盖从 20–35% 提到 52–65%，单次无双打到的人数大约翻倍。现有 60 关回归是按旧覆盖调的。实现后请先跑 npm run audit:campaign；如果通关率过高，优先调敌潮密度或怒气回复，别把范围再缩回去。

  2. 夏侯惇跳出期间普攻暂停

    0.9 秒内他不在城墙上，普攻停一下更好理解。也可以让普攻照常（不影响平衡），二选一。

  3. 刘备与孙权都从城门出发

    区分方式：刘备的援军沿每条路纵深推进（细长、跟路走），孙权的潮浪是关前半圆（宽、不跟路）。如果觉得还是像，孙权可以改成“沿路潮线”。

  4. 周瑜火船只走一路

    三路图上只烧压力最大的一路。现有局内强化“连营火势”（半径 +16）需改成“火带宽 +24”。

  5. 美术成本

    夏侯惇、许褚需要新增“跳起 / 落地”两帧动作，曹操需要令旗投掷物，刘备需要小兵群组件（可复用盾营盾牌），其余都是特效。按 art-design.md 的增量规则计费。

覆盖率按 12 张地图的敌军道路（y 0–530，每 4 单位取样）计算，领衔阵位 (210, 550)。它衡量“沿路分布的敌潮”能被罩住多少，不等于实际击杀；真实效果以战斗回归为准。
