02 · 武将

看头像，就知道强弱

原来每张卡都有四行字：名字、阵营·技能、等级/技能等级、“主线首通解锁”。新版卡面只保留名字。阵营靠卡框颜色区分；等级放在角标；锁定的将显示黑影，并直接写出解锁关卡。点开卡片，底部弹出详情，技能效果用小动画演示，不用文字描述。

  • “魏 · 魏武号令”→卡框蓝 / 绿 / 橙代表魏 / 蜀 / 吴，右上方块里写单字

  • 右上角“出战”贴纸→斜挂金色绶带

03 · 工坊

进度环代替说明文字

科技页原来是六张一模一样的长卡，每张都写着“尚未研究 / 每级 伤害 +2.5% · 范围 +1.5”。新版改成 3×2 的军营节点，每个节点外面套一圈等级进度环。选中节点后，下方用射程圈和对比条演示“升一级会变成什么样”，研究按钮写明花费。锻造页改成打铁和品质滚动的开箱演出。

  • “盾营 Lv0/10 · 尚未研究”→节点进度环填充比例 = 等级 / 10；可研究的节点带翠色“+”角标
  • “每级 伤害 +2.5% · 范围 +1.5”→射程圈：虚线是当前，翠色脉冲圈是下一级；对比条：金色是现有，闪烁翠色是增量
  • “先通过主线开放此军营”（换行 3 次）→节点变暗 + 锁形图标，点击后提示关卡号
  • 锻造：原生下拉框 + 品质按钮→铁砧敲三下，品质条滚动后停住，落定后放出光芒
  • “下次出阵生效”→研究完成时圆环闪金，同时弹出提示“已生效”

04 · 战斗

每一刀都要有回响

这块是实时运行的战场。营地会自动放箭，敌兵中箭会闪白、跳出伤害数字，倒下时溅墨。暴击用金色大字。点战场上的空营位，会弹出环形布阵菜单。怒气满了点主按钮，依次触发：武将切入 → 子弹时间 → 横扫光弧 → 震屏 → “一击横扫 N 人”。下方按钮可以直接触发任意事件。

  • “敌军 0 · 待入 49”“第 1 / 6 波 00:00”→城关血条下方加一排波次刻度：金色已过，闪烁是当前波，朱砂长块是敌将波
  • 城门掉血只缩血条，0.18s→白色残影血条慢 0.25s 追上 + 红色暗角 + 血条抖动 + 城门处飘出 −数值
  • 底部“部署军阵”大纸板挡住半屏→在营位上方展开环形三选一，买不起的选项灰掉；落营时砸地并扬起尘圈
  • 伤害数字 0.62s 上浮→弹出缩放（1.4→1）；暴击加大金字、描边和“暴”字
  • 震屏 1.5px / 0.18s→无双震屏 6px / 0.38s 衰减；城门受击 3px（减少动态效果时关闭）
  • 连斩小号文字→右上斜体大数字，每次击杀都弹一下；20 / 50 / 100 连斩分三档变色加光
  • 波次横幅淡入→书法大字从模糊中砸下，底下拉出墨条；敌将波用朱砂色

05 · 结算

2.5 秒，一记一记盖章

结算现在嵌在战场区域里，十四块内容挤在约 500px 高的空间中，上方的倍速按钮还能点。新版改成全屏结算，盖住战斗界面，按固定节奏逐项亮出：标题墨刷 → 三星依次盖章 → 高光数字滚动 → 四项统计翻牌 → 宝箱 → 按钮。随时点击屏幕都能跳到最终状态。资源奖励化成金币飞进顶栏，顶栏数字随之上涨。

  • “此阵，守住了。”+ 文字星 ★★★→书法大字“守住了”从左往右墨刷展开；三颗星依次盖章，中间那颗更大
  • “获得 4 册 · 720 铜 · 12 铁”→图标胶囊；开箱后金币飞向顶栏，顶栏弹跳、数字滚动
  • “开启胜利箱”文字框→宝箱每 2.2s 晃一下提示可点；点开后箱盖弹起，品质色光晕亮起，装备卡弹出
  • 下一阵 + 三个同等大小按钮 + 剧情文字→一个书法主按钮 + 三个图标小按钮；剧情移到下一阵的开场
  • 失败：“整军，再来。”+ 空的建议→朱砂“城破”+ 裂纹描出 + 两张可直达的强化建议卡

本次通读发现、需要一起修的问题

P0结算层没盖住战斗界面

结算层嵌在战场区域里，倍速按钮在胜负后仍可点。改为全屏结算层（见 05）。

P0提示条被弹窗遮住

.toast 的层级是 30，弹窗遮罩是 35，弹窗打开时的提示条都看不见。把提示条提到最上层，位置避开主按钮。

P1城门受击、建营、升级没有反馈

引擎会发出 leak / build / upgrade 事件，但 V1 渲染器没有处理。按动效表接入。

P1金色品质高光的选择器写错了

.result-loot-item.quality-gold 永远匹配不到，所有掉落都是同一个 0.38s 淡入。

P1“回军帐”去的是武将页

按钮文案和跳转目标不一致，应改为回征战页。

P1减少动态效果被 !important 绕过

tutorial-pulse 和 just-ready 在系统开启减少动态效果时仍在闪。

P2战场顶部信息挤在一起

地图名同时出现在 canvas 和 DOM 里，还和威胁提示、切入、引导卡共用同一条 40px 区域。新版只保留一处显示。

P2弹窗按钮没有主次

“取消”和“确认分解”用的是同一种绿。危险操作改用朱砂色，取消改用描边按钮。

07 · 待你决定

审核时请重点看这几处

  1. 用书法字体做标题和主按钮样机用的是 Ma Shan Zheng（Google Fonts，SIL OFL 许可）。可以打包进游戏，许可要登记到素材来源记录里；也可以换成自己选的字体。
  2. 关卡格改成行军地图每章 20 关时，一屏放 6–8 个节点，需要横向或纵向滚动。另一种做法是保留网格，只改卡片的视觉。
  3. 战前情报改为长按查看首屏会更干净，但新玩家可能发现不了。可以在前三关显示一次提示。
  4. 武将头像用书法单字徽章样机用单字代替立绘。正式版可以继续用现有的 SVG 头像套进圆章框，也可以等精修立绘做出来。
  5. 无双震屏 6px美术文档写的是“不超过 3px / 0.26s”。表现力优先的话建议放宽到 6px，需要你同意改文档。
  6. 结算 2.5 秒演出点击可以跳过。连续刷关时，是否让第二次起自动缩短到 1.2 秒？
