## 固定策略通关与大招对照

当前版本以正常解锁、出战人数限制、三核心推荐下限和真实军粮验证 mode6 策略；主线不要求金装备，科技审计也不佩戴任何掉落装备。零科技六十关回归与满科技连续账号报告分开核算，以免将额外成长收益当作最低通关门槛。

当前版本另以各关推荐下限培养、同一 mode6 建设策略和该关连续账号审计的科技快照关闭大招，Wei1、Wei20、Shu20、Wu20 分别在第 3、4、2、2 波失败，战斗时长 109.47、178.17、78.37、76.67 秒；对应科技等级上限为 0、4、8、10（仅已解锁军营）。这四个对照保存在当前 [playable-audit.json](data/playable-audit.json) 的 noUltimate 字段，证明该固定策略下科技成长仍保留武将技能的作用。回归未覆盖全部十五武将组合、所有练度和随机种子，也未测真人胜率或操作体验。

保留原型的三个种子回归曾在正常军粮下通关第八波，关闭无双均在第三波失败；原型共排定 999 人，活兵上限 160，投石每次最多伤害 6 人。该证据用于维护 `prototype.html`，不替代 V1 回归。

养成预算按曹操、关羽、夏侯惇三名早期主力计算：此前完成关卡的一星首通与免费首次追赶，不含每日重复收益；按推荐下限英雄等级、技能等级、主武器品质/等级，其他装备白 Lv0。十二段经验册、铜钱、精铁的静态缺口均为 0。S12 进入前需求 276 册、51690 铜、285 铁，此前一星首通可得 519 册、93200 铜、1162 铁。六十关一星首通合计 600 册、108600 铜、1338 铁；全三星合计 664 册、130320 铜、1566 铁，已计幕末 1.25 倍与新增星级取整。

科技与专属物品的完整数值及迁移规则见 [成长扩展设计](progression-design.md)。科技/装备满阶、概率边界、匹配专属效果、战鼓局部最大光环、投石基础间隔/目标数、快照、重复结算与迁移幂等均按实际规则回归。静态预算只证明费用与前置资源量；实际新账号审计另验证了培养扣款、首通发放和最高星奖励的连续状态变更，逐关状态见审计报告。任意换队不保证没有培养缺口，十五人全满与四槽满养成为长期可选目标。每日重复收益是本地日期软限制，不具备服务器防作弊能力。

## 交付物与后续验收

`dist/index.html` 为默认 V1 离线主线，`dist/prototype.html` 为原型；`dist/wushuang-v1-playable.zip` 为双入口离线试玩包，`docs/v1/index.html` 为离线文档阅读器，`dist/v1-design-package.zip` 为文档包。设计阅读器包含五份文档、地图/关卡摘要及 SVG 风格板；没有远程脚本、字体或图片依赖。构建采用临时文件完整写入后原子替换，并发构建回归验证运行数据和独立 HTML 不会暴露未完成版本。响应式代码与模拟事件验证不等于浏览器布局验收。美术参考板是方向参考，运行画面采用程序绘制资产。

发布前仍需真实浏览器与手机的首关引导、触控可达、三将技能操作、后台恢复、离线存储、导入导出、外放音频与长局帧率验收；TapTap 需实际 SDK 与对应宿主测试。还需扩大队伍/种子/练度、错误建设策略、首领阶段与控制覆盖测试，收集真人首招理解、失败原因和重试意愿。当前不声称全面平衡、手机验收通过或可直接上架。

长运营扩展沿用稳定的武将、章节、关卡、地图、成长段与军营 ID；新增内容同步生成器、运行数据、解锁/奖励、技能执行与绘制，审查存档迁移及前置资源。六十关是本版 manifest，后续章、武将和地图可扩展；科技、背包换装、装备转移与胜利箱已实现，后续活动与可信服务器结算需各自设计和实现。
